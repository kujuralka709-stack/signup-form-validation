# Signup Form Validation 📝

A simple and responsive Signup Form Validation project built using **HTML, CSS, and JavaScript**. This project validates user inputs and displays inline error messages to improve the user experience.

## ✨ Features

- Full name validation
- Email validation using Regular Expressions
- Password length and complexity validation
- Password strength indicator
- Confirm password validation
- Inline error messages
- Success message after valid input
- Responsive design for mobile and desktop
- Prevents successful form submission when inputs are invalid

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` using Live Server.
5. Enter your details and test the validation.

## 🔐 Validation Rules

- **Name:** Must contain at least 2 characters.
- **Email:** Must follow a valid email format.
- **Password:** Must contain at least 8 characters, one uppercase letter, one lowercase letter, and one number.
- **Confirm Password:** Must match the password entered above.

## 🎯 Project Objective

The objective of this project is to practise form validation, JavaScript DOM manipulation, regular expressions, event handling, and user feedback.

## 📚 Learning Outcomes

- Understanding HTML forms and input fields
- Applying CSS for responsive layouts
- Validating user input using JavaScript
- Displaying dynamic error messages
- Checking password strength

## ⚠️ Note

This is a front-end demonstration project. It does not create or store actual user accounts. A real signup application requires server-side validation and secure password handling.
